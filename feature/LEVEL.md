## New Feature: Dynamic Level Display

Feature Description: Introduce a level display that updates whenever the dynamic background changes. Each time the player reaches the next 100-point milestone, the game advances to the next level and displays a brief notification, such as “Level 2 Unlocked!”

### Requirements

* Start players at Level 1.

* Increase the level by one at every 100-point milestone, alongside the dynamic background transition.

* Display a clear, animated level-up notification (e.g., “Level 2 Unlocked!”).

* Keep the level visible in the game HUD so players can track their progress.

* Ensure the level display stays synchronized with background changes.

* Continue increasing levels as the game progresses, even after the background gradient palette loops.

* Make the display responsive and consistent across supported screen sizes.

### Acceptance Criteria

* The level increases at every 100-point milestone.

* The background transition and level-up notification happen together.

* The HUD always shows the current level.

* Levels continue progressing beyond the 10-background palette.

* The feature works smoothly without interrupting gameplay.
